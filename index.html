How to open the export in Canva (editable):
  1. Click Export to Canva (.pptx) on the left. A .pptx downloads.
  2. Go to canva.com → Create a design → Import file → select the .pptx.
  3. Every text box, image, icon and colour block is now editable in Canva. Move, replace, or restyle anything.
  4. Tip: keep the same A4 vertical layout (7.5 × 10 in) so nothing shifts when you import.
PPTX is the native Canva-editable format. PDF export is for quick sharing/printing. If you use Canva Teams, you can also “Share → Brand Kit” to lock the green/orange/blue to your brand.
